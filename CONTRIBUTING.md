# Contributing

This repository is a personal fork of Lenovo Legion Toolkit, maintained primarily for a Lenovo LOQ 15IRX10 (i5-13450HX, RTX 5050) and other compatible LOQ models.

If you want to contribute or report something:

- **Pull Requests:** Contributions are welcome. Please keep changes clean, test on your hardware, and ensure unit tests pass (`dotnet test`).
- **Issues:** If you hit a bug, open an issue with your exact model number, BIOS version, and toolkit logs (`Settings -> App -> Logging`).
- **Upstream:** For issues affecting standard Legion laptops or features unrelated to LOQ hardware, check the upstream project at [LenovoLegionToolkit-Team/LenovoLegionToolkit](https://github.com/LenovoLegionToolkit-Team/LenovoLegionToolkit).
