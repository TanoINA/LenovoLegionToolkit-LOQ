# Contributing

This repo is a personal fork of Lenovo Legion Toolkit that I maintain for a Lenovo LOQ 15IRX10 (i5-13450HX, RTX 5050) and similar LOQ models.

If you want to send a PR, test it on real hardware and make sure `dotnet test` passes before opening it. Keep changes focused.

If you hit a bug on a LOQ laptop, open an issue with your exact model number, BIOS version, and the app logs (`Settings -> App -> Logging`).

If the bug affects standard Legion laptops or has nothing to do with LOQ-specific fixes, report it upstream at [LenovoLegionToolkit-Team/LenovoLegionToolkit](https://github.com/LenovoLegionToolkit-Team/LenovoLegionToolkit).
